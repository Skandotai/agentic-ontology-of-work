Ontology / Assurance

Guardian

Assurance since 1.0 aow:Guardian

The oversight Actor that enforces Policy and Assurance Levels, monitors behavior, and escalates to people when needed.

Separates doing the work from checking the work, so that no Actor is its own only safeguard.

A kind of Actor.

Every entity also has an id and a type, and may carry label, description, and the provenance facet: version, created_at, created_by, revision_of.

Notes

A Guardian may be software, a person, or both. Because it is an Actor, its own interventions are Actions and leave the same trail as everyone else's.

Example

From examples/claims-processing.jsonld, which passes every validation gate.

{
  "id": "guardian-claims",
  "type": "Guardian",
  "name": "Claims guardian",
  "enforcement_mode": "preventive",
  "scope": "All eligibility decisions on disability claims.",
  "enforces": [
    "policy-auto-approval",
    "policy-high-risk-review",
    "aow:AL2"
  ],
  "oversees": [
    "agent-validation",
    "agent-coverage",
    "agent-benefit"
  ],
  "escalates_to": [
    "role-claims-adjuster"
  ]
}
