Ontology / Assurance

Memory

Assurance abstract since 1.0 aow:Memory

Persistent knowledge accumulated from experience, used to inform future Context.

Retains information from past work for use in future Context and audit.

Kinds: Operational Memory, Knowledge Base.

Attributes

AttributeTypeRequiredDescription
store_refuriWhere the memory is held.
retention_policytextHow long entries are kept and when they are purged.

Every entity also has an id and a type, and may carry label, description, and the provenance facet: version, created_at, created_by, revision_of.
