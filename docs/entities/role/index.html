Ontology / Execution

Role

Execution new in 2.0 since 2.0 aow:Role

A named set of responsibilities and authority that an Actor can fill, such as "claims adjuster" or "eligibility reviewer".

Allows Tasks, Policies, and escalations to target a responsibility instead of a specific person or agent.

Attributes

AttributeTypeRequiredDescription
responsibilitiesstring-listWhat an Actor in this Role is accountable for.
labelstringyesShort human-readable name.

Every entity also has an id and a type, and may carry label, description, and the provenance facet: version, created_at, created_by, revision_of.

Example

Source: examples/claims-processing.jsonld. The example passes all validation checks.

{
  "id": "role-eligibility-processor",
  "type": "Role",
  "label": "Eligibility processor",
  "responsibilities": [
    "Extract claim details",
    "Validate coverage",
    "Calculate benefit",
    "Record eligibility decisions within policy"
  ]
}
