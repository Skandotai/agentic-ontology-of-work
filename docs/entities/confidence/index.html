Ontology / Assurance

Confidence

Assurance since 1.0 aow:Confidence

A model-, rule-, or human-derived measure of certainty about an Observation, a Result, or an Action.

Allows autonomy to depend on certainty. An Agent acts without approval only when its Confidence meets the threshold for its Assurance Level.

Attributes

AttributeTypeRequiredDescription
valuenumber (0–1)yesCertainty between 0 and 1.
sourceone of model, heuristic, rule, ensemble, humanWhat produced the measure.
calibratedbooleanWhether the value has been calibrated against observed accuracy.
volatilityone of low, medium, highHow much the value is expected to move as evidence arrives.

Every entity also has an id and a type, and may carry label, description, and the provenance facet: version, created_at, created_by, revision_of.
