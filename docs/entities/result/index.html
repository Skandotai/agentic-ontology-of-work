Ontology / Execution

Result

Execution since 1.0 aow:Result

The immediate, atomic effect or output of an Action.

Records what an Action changed or produced, so that it can be verified, rolled up into Outcomes, and fed back.

Attributes

AttributeTypeRequiredDescription
statusone of success, partial, failureWhether the Action achieved what it set out to.
summarytextWhat the Result is, in words.
artifactsuri-listDocuments, records, or state changes the Result produced.

Every entity also has an id and a type, and may carry label, description, and the provenance facet: version, created_at, created_by, revision_of.

Notes

A Result is local and immediate. An Outcome is aggregated and business-level.

Example

From examples/claims-processing.jsonld, which passes every validation gate.

  "id": "res-coverage-84933",
  "type": "Result",
  "status": "success",

  "generated_by": "act-coverage-84933"
}
