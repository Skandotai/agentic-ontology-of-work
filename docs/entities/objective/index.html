Ontology / Cognition

Objective

Cognition since 1.0 aow:Objective

A business-level goal expressed in strategic or operational terms.

Connects agentic activity to specific, measurable enterprise value.

Attributes

AttributeTypeRequiredDescription
kpi_targetstringThe measurable target, for example "claims cycle time -20%".
priorityone of low, medium, high, criticalRelative business priority.
time_horizonstringThe period over which the Objective is pursued, for example "FY2027".
descriptiontextyesLonger human-readable explanation.

Every entity also has an id and a type, and may carry label, description, and the provenance facet: version, created_at, created_by, revision_of.

Example

From examples/claims-processing.jsonld, which passes every validation gate.

{
  "id": "obj-claims-cycle-time",
  "type": "Objective",
  "label": "Faster disability claims",
  "description": "Reduce disability claims cycle time by 20% without increasing claims leakage.",
  "kpi_target": "Median cycle time -20% against the FY2026 baseline; leakage no higher than baseline.",
  "priority": "high",
  "time_horizon": "FY2027"
}
