Ontology / Assurance

Operational Memory

Assurance since 1.0 aow:OperationalMemory

Short-lived, execution-oriented memory scoped to a session, Task, or Work Item.

Carries state across the steps of a single piece of work.

A kind of Memory.

Attributes

AttributeTypeRequiredDescription
store_refuriWhere the memory is held. (from Memory)
retention_policytextHow long entries are kept and when they are purged. (from Memory)

Every entity also has an id and a type, and may carry label, description, and the provenance facet: version, created_at, created_by, revision_of.
