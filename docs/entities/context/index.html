Ontology / Cognition

Context

Cognition since 1.0 aow:Context

The structured situational information that gives relevance to an Intent.

Makes the same Intent resolve differently for different situations, and records what an Actor knew when it acted.

Attributes

AttributeTypeRequiredDescription
context_typeone of environmental, procedural, data, historical, sessionThe kind of situational information.
variablesjsonThe situational values themselves.
sensitivity_levelone of public, internal, confidential, restrictedHandling classification.
valid_untildatetimeWhen the Context should be considered stale.

Every entity also has an id and a type, and may carry label, description, and the provenance facet: version, created_at, created_by, revision_of.

Example

From examples/claims-processing.jsonld, which passes every validation gate.

{
  "id": "ctx-claims-procedure",
  "type": "Context",
  "label": "Disability claims procedure",
  "context_type": "procedural",
  "variables": {
    "procedure": "LTD eligibility v7",
    "regulatory_regime": "state insurance code",
    "service_level_hours": 48
  },
  "sensitivity_level": "internal",
  "draws_on": [
    "kb-claims"
  ]
}
